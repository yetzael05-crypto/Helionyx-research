# Helionyx Research - Luxury E-Commerce Platform

A premium scientific e-commerce website featuring research compounds with certificates of analysis, built with Next.js, TypeScript, and Tailwind CSS.

## Design Philosophy

Blending the elegance of Apple, innovation of Tesla, and credibility of high-end biotechnology companies.

### Color Palette
- **Deep Black**: #050505
- **Gunmetal Gray**: #2a2e31
- **Platinum Silver**: #e8e8e8
- **Gunmetal Gray Accents**: #c0c0c0

### Typography
- **Headings**: Cinzel (Elegant Serif)
- **Body**: Montserrat (Modern Sans-Serif)

## Features

✨ **Premium Design**
- Luxury glass-morphism effects
- Cinematic hero sections
- Molecular graphics and animations
- Responsive mobile design

🛍️ **E-Commerce**
- Product catalog with categories
- Shopping cart management
- Product details with strength selection
- Secure checkout flow

🔬 **Research Features**
- Certificate of Analysis (COA) integration
- Product purity guarantees
- Quality testing documentation
- Research standards verification

👨‍💼 **Admin Dashboard**
- Product management
- Price and inventory control
- Customer order tracking
- Analytics

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Project Structure

```
src/
├── app/                 # Next.js pages and layouts
├── components/          # React components
│   ├── Navigation.tsx   # Main navigation
│   ├── Footer.tsx       # Footer component
│   └── home/            # Homepage components
├── store/               # Zustand stores
│   └── cartStore.ts     # Shopping cart state
└── styles/              # Global styles
```

## Technology Stack

- **Framework**: Next.js 14
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **Animations**: Framer Motion
- **Icons**: React Icons
